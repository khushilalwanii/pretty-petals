# Pretty Petals 🌸

**Pretty Petals** is an online flower shop website that allows users to browse and buy flowers and arrangements for various occasions. It also features a **Flash Sale** section for flowers that perish quickly, promoting sustainability.  

## Features
- Browse flowers by category (Birthday, Anniversary, etc.)
- Flash Sale section for discounted flowers
- Admin panel for managing inventory and orders
- User panel for easy browsing and ordering
- Responsive design for desktop and mobile

## Tech Stack
- HTML, CSS, JavaScript for frontend
- PHP & SQL for backend and database
- Fully functional e-commerce features
